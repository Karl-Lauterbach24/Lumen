# Lumen 1.0.0

A disc and cinema player for Blu-ray (including 3D and disc menus), DVD, HD DVD, Video CD, audio CD and
Digital Cinema Packages. It also plays streams and connects to Jellyfin, Emby and Plex.

## Downloads

| System | x86-64 (Intel/AMD) | ARM64 |
|--------|--------------------|-------|
| Windows 10/11, installer | `Lumen-1.0.0-windows-x64.msi` | `Lumen-1.0.0-windows-arm64.msi` |
| Windows 10/11, portable | `Lumen-1.0.0-windows-x64.zip` | `Lumen-1.0.0-windows-arm64.zip` |
| macOS 15 | `Lumen-1.0.0-macos-x64.dmg` (Intel) | `Lumen-1.0.0-macos-arm64.dmg` (Apple Silicon) |
| Debian 13 and derivatives | `Lumen-1.0.0-linux-amd64.deb` | `Lumen-1.0.0-linux-arm64.deb` |
| Fedora 44 | `Lumen-1.0.0-linux-x86_64.rpm` | `Lumen-1.0.0-linux-aarch64.rpm` |

`SHA256SUMS.txt` lists the checksums. Linux: `sudo apt install ./Lumen-….deb` or `sudo dnf install ./Lumen-….rpm`.

## New in 1.0.0

- **Packages for both architectures on every platform**: Windows on ARM, Intel Macs and Linux on ARM64 are new.
  The updater picks the package that matches the installed build.
- **Recently played** on the start page: files, images and disc folders you played, one click to reopen.
  Files resume where you stopped.
- **Drag and drop**: drop a file, folder or link on the control window to play it.
- **Help dialog** (F1 or the ? button): version, licence, links and all keyboard shortcuts.
- **Night mode** in the Audio tab: quiet passages louder, loud ones quieter. It has no effect on bitstream output.
- **External subtitle files** can be loaded in the Subtitles tab.
- **Volume and night mode are remembered** between sessions.
- **Audio CDs** show the cover of an identified disc next to the title, and the track list no longer offers
  video-disc buttons.
- **The window title** shows what is playing.
- **16 interface languages**: Swedish, Czech, Turkish, Ukrainian, Russian, Japanese, Simplified Chinese and
  Korean are new. The README exists in the same 16 languages.
- **Plugins for every architecture**: a plugin can ship separate native libraries for ARM64 on Windows and
  Linux (`windows-arm64`, `linux-arm64`) and a universal library for macOS. The store installs the matching one.
- Fixed: a built-in output profile that had been saved once lost its translated name.

## Notes

- English and German texts are maintained by hand. The other 14 translations of the interface and the README
  were made with machine assistance and have not been reviewed by native speakers; corrections are welcome.
- Tested automatically for every package: build, package installation and start of the control window
  (Windows: MSI install, start, upgrade and uninstall; macOS: self-contained app bundle; Linux: `apt`/`dnf`
  install in a clean container). The full playback test suite runs on Windows x64 and macOS ARM64, a part of
  it on Linux.
- Not tested: playback on real hardware for Windows ARM64, Intel Macs and Linux (the CI machines have no GPU,
  so the player window cannot be shown there), and reading physical discs in a drive on any platform. Audio
  CDs, DVDs, Video CDs and DCPs are tested with images and generated test material.
- Blu-ray 3D decoding (FFmpeg-mvc) is included in the Windows x64 package only; elsewhere 3D discs play in 2D.
- Debian 13 ships libdvdnav 6: DVD menus and playback work, but seeking in DVDs is less exact, the region
  code is not shown and the DVD navigator is not told about audio/subtitle changes.
- The RPM needs the Qt version Fedora 44 ships, so it will not install on other Fedora releases. On Linux,
  Lumen reports new versions but does not install them itself.
- Lumen contains **no** copy-protection circumvention. AACS, BD+ and CSS work only with libraries you add
  yourself through a plugin.
- The Windows packages are not code-signed (SmartScreen: "More info" → "Run anyway"). The macOS apps are
  signed ad hoc, not notarized: right-click `Lumen.app` → **Open**, or run
  `xattr -dr com.apple.quarantine /Applications/Lumen.app`.
