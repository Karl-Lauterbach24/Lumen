# Lumen 0.2.2

A Windows installer.

## Downloads

| System | File |
|--------|------|
| Windows 10/11 (x64), installer | `Lumen-0.2.2-windows-x64.msi`: installs to `C:\Program Files\Lumen` with a Start menu entry |
| Windows 10/11 (x64), portable | `Lumen-0.2.2-windows-x64.zip`: unzip and start `lumen.exe` |
| macOS 15 (Apple Silicon) | `Lumen-0.2.2-macos-arm64.dmg` |
| Debian 13 and derivatives (x86-64) | `Lumen-0.2.2-linux-amd64.deb`: `sudo apt install ./Lumen-0.2.2-linux-amd64.deb` |
| Fedora 44 (x86-64) | `Lumen-0.2.2-linux-x86_64.rpm`: `sudo dnf install ./Lumen-0.2.2-linux-x86_64.rpm` |

`SHA256SUMS.txt` lists the checksums.

## New in 0.2.2

- **MSI installer for Windows.** It installs Lumen for all users, adds a Start menu entry and can be removed
  through *Apps & features*. Installing a newer MSI replaces the older version. For unattended installation:
  `msiexec /i Lumen-0.2.2-windows-x64.msi /qn`.
- **Updates through the installer.** A copy installed with the MSI updates itself by downloading the new MSI,
  checking it against `SHA256SUMS.txt` and running it; Windows asks for administrator rights. The portable
  copy keeps updating from the ZIP.

Your settings and plugins stay where they are; installer and portable copy share them.

## Notes

- The MSI is not code-signed, so Windows shows an "unknown publisher" prompt and SmartScreen may ask for
  confirmation ("More info" → "Run anyway").
- A portable copy does not turn into an installed one by itself: to switch, install the MSI and delete the
  portable folder.
- Everything else is unchanged from 0.2.1, including the notes about the Linux packages (not yet tested on a
  real desktop; Debian 13's older libdvdnav limits some DVD functions) and about audio CDs (tested with
  images, not with a physical drive).
- Lumen contains **no** copy-protection circumvention. AACS, BD+ and CSS work only with libraries you add
  yourself through a plugin.
- The macOS app is signed ad hoc, not notarized. On first start, right-click `Lumen.app` → **Open**, or run
  `xattr -dr com.apple.quarantine /Applications/Lumen.app`.
