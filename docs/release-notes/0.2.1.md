# Lumen 0.2.1

Linux packages, and discs that tell you what they are.

## Downloads

| System | File |
|--------|------|
| Windows 10/11 (x64) | `Lumen-0.2.1-windows-x64.zip`: portable, unzip and start `lumen.exe` |
| macOS 15 (Apple Silicon) | `Lumen-0.2.1-macos-arm64.dmg` |
| Debian 13 and derivatives (x86-64) | `Lumen-0.2.1-linux-amd64.deb`: `sudo apt install ./Lumen-0.2.1-linux-amd64.deb` |
| Fedora 44 (x86-64) | `Lumen-0.2.1-linux-x86_64.rpm`: `sudo dnf install ./Lumen-0.2.1-linux-x86_64.rpm` |

`SHA256SUMS.txt` lists the checksums.

## New in 0.2.1

- **Linux packages (DEB and RPM).** They install the program, a desktop entry and an icon; Qt 6, libmpv and
  the disc libraries come from your distribution.
- **Disc identification plugin** in the plugin store. Audio CDs get album, artist, year, cover and track
  names from MusicBrainz. DVDs, Blu-rays and Video CDs get a film title and year, found on Wikidata from
  the disc label. The plugin sends the CD's disc ID or the disc label to those services; nothing is sent
  unless you install and enable it.
- **Audio CDs**
  - Lumen reads CD-Text and shows album and track names without any plugin.
  - CD images (CUE/BIN and other formats libcdio reads) now play, with one chapter per track.
  - Fixed: audio CDs did not start with current mpv versions (renamed mpv option).
- **Plugins**
  - mpv scripts receive Lumen's events, can fetch URLs through Lumen and can set disc metadata and a
    status line.
  - Native plugins get `set_disc_info`. Existing plugins keep working unchanged.
  - The `disc` event now carries the disc name, the titles and, for audio CDs, the MusicBrainz disc ID and
    the table of contents.

## Notes

- The Linux packages are built and installed in CI on Debian 13 and Fedora 44, where the control window is
  started as a check. They are not yet tested on a real desktop with a drive. The RPM needs the Qt version
  Fedora 44 ships (6.11), so it will not install on other Fedora releases.
- Debian 13 ships libdvdnav 6. With it DVD menus and playback work, but seeking in DVDs is less exact, the
  region code is not shown and the DVD navigator is not told about audio/subtitle changes. The other
  packages use libdvdnav 7.
- The Linux packages do not include the FFmpeg-mvc decoder: Blu-ray 3D discs play in 2D. On Linux, Lumen
  reports new versions but does not install them itself.
- Audio-CD playback is tested with images; reading a physical CD in a drive uses the same code path but
  is not yet tested with real hardware.
- Lumen contains **no** copy-protection circumvention. AACS, BD+ and CSS work only with libraries you add
  yourself through a plugin.
- The macOS app is signed ad hoc, not notarized. On first start, right-click `Lumen.app` → **Open**, or run
  `xattr -dr com.apple.quarantine /Applications/Lumen.app`.
- The Windows build is not code-signed, so SmartScreen may ask for confirmation ("More info" → "Run anyway").
