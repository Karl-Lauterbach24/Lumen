# Lumen 0.2.0

A disc and cinema player for Blu-ray (including 3D and disc menus), DVD, HD DVD, Video CD, audio CD and
Digital Cinema Packages. It also plays streams and connects to Jellyfin, Emby and Plex.

## Downloads

| System | File |
|--------|------|
| Windows 10/11 (x64) | `Lumen-0.2.0-windows-x64.zip`: portable, unzip and start `lumen.exe` |
| macOS 15 (Apple Silicon) | `Lumen-0.2.0-macos-arm64.dmg` |

`SHA256SUMS.txt` lists the checksums, and Lumen's built-in updater verifies them before it installs anything.

## New in 0.2.0

- **Streaming**:
  - links of all kinds (HTTP(S), HLS, DASH, RTSP, RTMP, SRT, UDP, SMB), with pages like YouTube through yt-dlp;
  - media servers: **Jellyfin, Emby and Plex**, with libraries, series, search and continue watching;
  - progress is reported back to the server.
- **Plugin store**:
  - plugins install from [Lumen-Plugins](https://github.com/Karl-Lauterbach24/Lumen-Plugins) or from your own sources;
  - every file is checked against its SHA-256 checksum.
- **Plugin system**: native C plugins, mpv scripts, and disc libraries you provide yourself.
- **Dolby Atmos / IAB in DCPs**: rendered to 7.1.4, 5.1.4, 7.1, 5.1 or stereo.
- **Video CD menus (PBC)** and a fix for reading chapters on real VCDs.
- **Automatic screens**: the player runs on the highest-resolution screen, the control window on the smallest.
- **Updater**: checks GitHub and updates with one click (Windows, macOS).
- **macOS**: an app bundle with an embedded player window, and a DMG.
- **English** is now the default language, and you can switch languages on the start page. There are 8 languages in total.
- **New logo.** Lumen is now licensed under the **AGPL-3.0-or-later**.

## Notes

- Lumen contains **no** copy-protection circumvention. AACS, BD+ and CSS work only with libraries you add
  yourself through a plugin.
- Blu-ray 3D needs the FFmpeg-mvc decoder. The Windows package includes it if the build succeeded in CI; otherwise
  3D discs play in 2D.
- Not yet tested with real cinema DCPs/KDMs, real Atmos mixes or pressed VCDs. See the README for details.
